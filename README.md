# TONE — daily English prototype

無料の日常英語学習サービスを検証するための、ローカル専用プロトタイプです。オリジナル教材8本を同梱し、APIキー・アカウント・外部依存パッケージは必要ありません。

## 起動

Node.js 20以上があるパソコンで、このリポジトリをクローンするかZIPを展開し、フォルダを開きます。

```sh
npm start
```

ブラウザで http://127.0.0.1:4173 を開いてください。終了はターミナルで Ctrl+C。別のポートを使う場合は `PORT=4174 npm start`。npm install は不要です。ES Modulesを使うため、index.htmlの直接ダブルクリックでは動きません。

サーバーは127.0.0.1だけにバインドします。公開・LAN公開はしていません。スマートフォン実機への配信は、この納品には含みません。

## できること

- オリジナルのミニドラマ5本、普遍的な科学の短い解説3本。A1 / A2 / B1
- 「字幕なしで聴く → 意味を選ぶ → 英文・日本語・音のポイント → 違う場面で使う」
- 文ごとの再生、0.85× / 1.0× / 1.15×、一時停止・再開・やり直し
- 料理中を想定した「英語の問い → 6.5秒の応答時間 → お手本 → 3.5秒の反復時間」を3回、自動進行
- 学習後の自己判断による復習日設定。初回の「できた」は3日後、その後7 → 14 → 30日。「もう一度」は翌日
- 復習一覧と学習履歴を、このブラウザのlocalStorageに保存。保存直後に読み戻して確認
- レッスンとモードのURLハッシュ。戻る・進む・別レッスンへの移動時に音声を取消
- 日本語UI、モバイル向けレイアウト、キーボード操作、Reduced Motionへの対応

## 音声とプライバシー

音声はブラウザのWeb Speech APIによる端末読み上げです。プロの録音や自然会話の音声ではありません。利用可能な英語のローカル音声を優先し、ない場合は端末側の既定の英語音声を使用します。端末・OSの音声エンジンによって通信が必要になる場合があります。音声品質・発音・対応状況は端末に依存します。

アプリ自体には外部API・解析・広告・フォント配信・画像配信へのリクエストがありません。マイクを使わず、声の録音・音声認識・自動採点はしません。学習進捗はサーバーに送りません。

画面を非表示にしたりロックしたりすると、安全のため一時停止します。画面を開いたまま使い、戻ったときに「再開」を押してください。話している文の途中で止めた場合、再開はその文の先頭からです。通勤時のバックグラウンド再生は、今後の別実装・実機検証が必要です。

音声が使えなくても、英文・訳・理解問題・応用問題を使えます。音声を完走しなかった場合に「聴いた」と記録・表示しないようにしています。学習記録は教材を自分で復習する目安であり、習得や発音能力の認定ではありません。

ブラウザの保存が無効・容量超過の場合は警告を表示し、その画面内だけの記録になります。ブラウザデータを削除すると履歴が消えます。同期・アカウント復旧はありません。

## 設計

主役は常に一枚の学習サーフェス。準備・再生待ち・実際の音声再生・回答・解説・復習の状態へ、そのサーフェスが変化します。音声開始表示は実際のonstart、完了は最後のonend、保存完了はlocalStorageの読み戻しに基づきます。応答時間の表示だけは、明示したタイマーです。

派手な発光、粒子、無意味なバウンスは使いません。Reduced Motionでは移動・アニメーションを止めます。デザインはタイポグラフィと少数のサーフェスに絞り、本文の視認性を優先しています。

## 検証

```sh
npm run check
```

詳細は `QA.md`。音声エンジンを模した決定的な状態テストとDOMスタブのフローテストは、実ブラウザ・実機の音声検証を代替しません。

## 現段階で含まれないもの

- 本番配信、アプリストア公開、広告、決済、サブスクリプション
- 有料AI、個別の会話生成、自動発音採点、音声認識
- 録音音声、映画のクリップ、ニュース記事の転載
- アカウント同期、通知、バックグラウンド再生、オフラインPWAのインストール

教材は新規のオリジナル例文です。科学解説は一般的で変わりにくい基礎事項で、時事ニュースではありません。本番品質では教材レビューと自然音声の制作方針を別途検証してください。

## 構成

- `index.html` / `styles.css`: 一枚の学習サーフェスとレスポンシブUI
- `app.js`: 学習フロー、ナビゲーション、イベント処理
- `lessons.js`: 8本の教材
- `audio.js`: キャンセル可能な音声・応答時間の状態機械
- `progress.js`: 復習間隔とlocalStorageの検証
- `server.mjs`: 依存なしのローカルHTTPサーバー
- `tests/`: 状態・教材・フローのテスト

試作名TONEは仮称です。商標調査は行っていません。
